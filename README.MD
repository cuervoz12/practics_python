# PRACTICA_EJERCICIOS_CON_PYTHON

Este repositorio se realiza con el fin de **repasar y reforzar la lógica de programación y el lenguaje Python** mediante diferentes ejercicios prácticos.

## Estructura del repositorio

Las carpetas `part(numero)` contienen diferentes ejercicios de lógica y programación.

Dentro de cada carpeta se encuentran varios archivos `.py`, donde se desarrollan los ejercicios correspondientes, y un archivo `README.md` que contiene notas, explicaciones y apuntes relacionados con los ejercicios de esa sección.

## Objetivo

El objetivo de este repositorio es **practicar y repasar conceptos de lógica de programación y del lenguaje Python**, mediante la realización de diferentes ejercicios.

Cada carpeta `part(numero)` contiene una serie de ejercicios que permiten reforzar los conocimientos adquiridos y mejorar la lógica al momento de programar en Python.
