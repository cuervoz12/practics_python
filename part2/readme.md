```
-pop: Otra característica fundamental de las listas en Python es que podemos eliminar cualquiera de sus componentes llamando al método pop e indicando la posición del elemento a borrar.

- Otra cosa que hay que hacer notar que cuando un elemento de la lista se elimina no queda una posición vacía, sino se desplazan todos los elementos de la derecha una posición.

- sort: es un método de Python que permite ordenar automáticamente los elementos de una lista de menor a mayor.

- sort(reverse=True) ordena automáticamente una lista de mayor a menor.

- se puede retornar listas.

- Funciones con valores por defecto en Python: Son funciones que tienen un valor preestablecido para un parámetro. Si no le pasas un valor, Python usa ese valor automáticamente [En resumen: el valor por defecto se utiliza cuando no proporcionas un argumento.], tambien se debe tener en cuenta que se debe poner al final para evitar errores 

- Argumentos nombrados: son argumentos que se pasan a una función indicando el nombre del parámetro al que pertenece el valor. Esto permite identificar claramente qué valor recibe cada parámetro y también cambiar el orden de los argumentos.

- end en print(): end indica qué debe colocar print() al finalizar. Por defecto, print() utiliza un salto de línea (\n). Si usamos end="", evitamos el salto de línea.

- sep en print(): sep significa separador. Indica qué se coloca entre los diferentes valores que pasamos a print().
```
